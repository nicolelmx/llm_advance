# Docker 构建失败 - 快速解决方案

## 问题
无法从 Docker Hub 拉取镜像：`TLS handshake timeout`

## 解决方案（按优先级）

### ✅ 方案1：配置 Docker 镜像加速器（推荐，一次配置永久有效）

#### Windows Docker Desktop 配置步骤：

1. **打开 Docker Desktop**
2. **点击右上角设置图标（⚙️）**
3. **选择 "Docker Engine"**
4. **在 JSON 编辑器中添加以下内容**：

```json
{
  "registry-mirrors": [
    "https://docker.mirrors.ustc.edu.cn",
    "https://hub-mirror.c.163.com",
    "https://mirror.baidubce.com"
  ]
}
```

5. **点击 "Apply & Restart"** 按钮
6. **等待 Docker 重启完成**
7. **重新运行构建命令**：

```powershell
docker-compose build
```

#### 验证配置是否生效：

```powershell
docker info | Select-String "Registry Mirrors"
```

如果看到镜像地址列表，说明配置成功。

---

### ✅ 方案2：使用国内镜像源直接修改 Dockerfile（临时方案）

如果方案1不适用，可以直接修改 Dockerfile 使用国内镜像：

**修改 Dockerfile 第2行**：

```dockerfile
# 原行：
FROM python:3.10-slim

# 改为（使用阿里云镜像）：
FROM registry.cn-hangzhou.aliyuncs.com/acs/python:3.10-slim
```

或者使用其他国内镜像：

```dockerfile
# 中科大镜像（如果可用）
FROM docker.mirrors.ustc.edu.cn/library/python:3.10-slim
```

---

### ✅ 方案3：手动拉取镜像后构建

如果网络不稳定，可以分步操作：

```powershell
# 1. 先手动拉取镜像（可以多试几次）
docker pull python:3.10-slim

# 2. 拉取成功后，再构建
docker-compose build
```

---

### ✅ 方案4：使用代理（如果有VPN/代理）

如果有可用的代理：

1. **Docker Desktop → Settings → Resources → Proxies**
2. **配置代理服务器**
3. **Apply & Restart**

---

## 推荐操作流程

1. **首先尝试方案1**（配置镜像加速器）- 这是最彻底的解决方案
2. **如果方案1不行，尝试方案3**（手动拉取镜像）
3. **如果还是不行，使用方案2**（修改 Dockerfile）

---

## 常见问题

### Q: 配置镜像加速器后还是失败？
A: 检查：
- Docker Desktop 是否已重启
- 镜像地址是否正确
- 网络连接是否正常

### Q: 如何确认配置已生效？
A: 运行：
```powershell
docker info | Select-String "Registry Mirrors"
```

### Q: 可以同时使用多个镜像源吗？
A: 可以，Docker 会按顺序尝试，第一个失败会尝试下一个。
