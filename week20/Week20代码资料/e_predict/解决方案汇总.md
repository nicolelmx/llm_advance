# Docker 镜像拉取失败 - 完整解决方案

## 问题分析
所有镜像源都无法访问，可能原因：
1. 网络环境限制
2. 镜像加速器配置未生效
3. 防火墙/代理设置问题

## 解决方案（按优先级）

### ✅ 方案1：检查并修复镜像加速器配置

#### 步骤1：验证当前配置
```powershell
docker info | Select-String -Pattern "Registry Mirrors" -Context 0,10
```

#### 步骤2：如果配置为空或未生效
1. **完全重启 Docker Desktop**
   - 右键系统托盘 Docker 图标 → Quit Docker Desktop
   - 等待完全退出后重新启动

2. **检查配置文件位置**
   - Windows: `C:\Users\你的用户名\.docker\daemon.json`
   - 确保文件内容正确

3. **尝试不同的镜像加速器配置**
```json
{
  "builder": {
    "gc": {
      "defaultKeepStorage": "20GB",
      "enabled": true
    }
  },
  "experimental": false,
  "registry-mirrors": [
    "https://dockerproxy.com",
    "https://docker.mirrors.ustc.edu.cn",
    "https://hub-mirror.c.163.com"
  ]
}
```

---

### ✅ 方案2：手动拉取镜像（绕过构建过程）

如果镜像加速器配置正确，可以尝试手动拉取：

```powershell
# 尝试拉取 Python 镜像
docker pull python:3.10-slim

# 如果失败，尝试使用完整镜像地址
docker pull docker.mirrors.ustc.edu.cn/library/python:3.10-slim

# 拉取成功后，再构建
docker-compose build
```

---

### ✅ 方案3：使用代理/VPN（如果有）

如果有可用的代理或VPN：

1. **Docker Desktop 代理配置**
   - Settings → Resources → Proxies
   - 配置 HTTP/HTTPS 代理
   - Apply & Restart

2. **系统代理**
   - 确保系统代理设置正确
   - Docker Desktop 会自动使用系统代理

---

### ✅ 方案4：使用本地 Python 环境（推荐，最可靠）

如果 Docker 环境无法使用，可以直接在本地运行脚本：

#### Windows 环境设置：

```powershell
# 1. 检查 Python 版本（需要 Python 3.8+）
python --version

# 2. 安装依赖
pip install -r requirements.txt

# 3. 直接运行脚本
python XGBoost2pre.py --normalize
```

**优点：**
- 不需要 Docker
- 运行速度更快
- 没有网络问题
- 调试更方便

**缺点：**
- 需要本地安装 Python 和依赖
- 环境可能不统一

---

### ✅ 方案5：使用预构建的镜像（如果有）

如果你有其他机器已经构建好的镜像：

```powershell
# 导出镜像
docker save xgboost-predict > xgboost-predict.tar

# 在目标机器导入
docker load < xgboost-predict.tar
```

---

### ✅ 方案6：修改 Dockerfile 使用更小的基础镜像

尝试使用 Alpine Linux（体积更小，可能更容易拉取）：

```dockerfile
FROM python:3.10-alpine

# Alpine 需要安装编译工具
RUN apk add --no-cache \
    gcc \
    musl-dev \
    linux-headers \
    fontconfig \
    ttf-wqy-zenhei \
    ttf-wqy-microhei
```

## 推荐操作流程

1. **首先尝试方案1**（检查镜像加速器配置）
2. **如果不行，尝试方案2**（手动拉取镜像）
3. **如果还是不行，使用方案4**（本地 Python 环境）- **这是最可靠的方案**
