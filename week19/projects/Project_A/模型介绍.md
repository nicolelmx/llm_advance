# 项目概述：信用卡欺诈风险预测基线（Project A）

## 这个项目是做什么的？
- **目标**：对信用卡交易进行二分类，预测交易是否存在欺诈风险。
- **应用场景**：支付/电商风控、实时拦截、人工复核优先级。
- **价值**：在低延迟下给出风险分数，辅助决策，降低欺诈损失。

## 解决了什么问题？
- 给每笔交易一个风险分数（0~1）与标签（0/1），可用于：
  - 实时拦截高风险交易，降低坏账/欺诈损失。
  - 将风险中等的交易推送人工审核，优化人力成本。
  - 为后续策略引擎/规则提供输入特征（特征可扩展）。

## 数据与特征
- 数据集：Kaggle `creditcard.csv`（匿名化 PCA 特征）+ `Amount`、`Time`，标签 `Class`。
- 特征维度：30 个输入特征（`Time`、`V1`~`V28`、`Amount`）。
- 预处理：标准化；Train/Test 分层切分；保留列顺序 `columns.json`。

## 模型与性能
- 模型：LightGBM 二分类基线，处理类别不平衡。
- 指标（示例训练结果）：Test AUC ≈ 0.9363。
- 导出格式：`lgbm_model.pkl`、`lgbm_model.txt`、`lgbm_model.onnx`（支持 CPU 推理）。

## 代码与服务
- 训练/推理脚本：
  - `src/preprocess.py`：清洗、切分、标准化，输出 processed 数据与列文件。
  - `src/train_lgbm.py`：训练、早停、导出 pkl/txt/onnx。
  - `src/infer.py`：批量推理，支持 ONNX/pkl。
  - `src/sample_json.py`：从测试集抽取一条样本并打印 `/predict` 可用的 JSON。
- 在线服务（FastAPI）：
  - 启动：`python src/api/app.py`（默认 0.0.0.0:8000）
  - 端点：
    - `GET /`：服务信息
    - `GET /health`：健康检查
    - `GET /docs`：Swagger UI
    - `POST /predict`：输入 30 维特征，返回 `score` 与 `label`
  - ONNX 优先加载；自动列校验；自动应用标准化。

## 输入/输出
- **输入**：JSON，键为 `Time`、`V1`~`V28`、`Amount`，共 30 项，全部为数值。
- **输出**：
  ```json
  { "score": 0.12345, "label": 0 }
  ```
  - `score`: 风险分数（0~1，越高风险越大）
  - `label`: 预测标签（0=正常，1=疑似欺诈）

## 运行流程（简要）
1) 安装依赖：`pip install -r requirements.txt`
2) 预处理：`python src/preprocess.py`
3) 训练：`python src/train_lgbm.py`
4) 批量推理（示例）：`python src/infer.py --input data/processed/test.parquet --model models/lgbm_model.onnx --output predictions.parquet`
5) 启动 API：`python src/api/app.py`，在 `http://localhost:8000/docs` 测试 `/predict`
6) 若需示例输入，运行：`python src/sample_json.py`

## 适用与局限
- 适用：二分类风险预测、需要低延迟推理的场景；可扩展接入更多业务特征。
- 局限：示例数据为匿名 PCA 特征，脱敏后可解释性有限；生产需要接入真实业务特征，并做更严格的数据清洗、漂移监控与规则/模型联动。

## 可扩展方向
- 特征：加入设备、地理、商户、用户画像、时序/图特征。
- 模型：对比 XGBoost/CatBoost；或蒸馏到更轻量的模型；加入阈值/代价敏感优化。
- 部署：ONNX 量化（ort quantization）、Docker/K8s、AB 实验、监控告警（延迟/召回/误杀/漂移）。
