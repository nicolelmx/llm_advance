# Project_B 操作手册

## 项目简介

Project_B 是一个整合了传统机器学习模型（LightGBM）和本地大语言模型（Ollama qwen3:4b）的智能风控系统。它不仅提供欺诈预测，还能使用LLM生成可读的解释报告和策略建议。

### 核心功能
1. **预测功能**：使用LightGBM模型预测信用卡交易是否为欺诈
2. **SHAP解释**：分析哪些特征对预测结果影响最大
3. **LLM解释**：使用qwen3:4b生成通俗易懂的中文解释报告
4. **策略建议**：针对高风险交易生成风控策略建议

  -H "Content-Type: application/json" `
  -d '{\"features\": {...}, \"explain\": false}'

### 5.3 使用Python测试

```python
import requests
import json

url = "http://localhost:8001/predict"

# 使用Project_A的sample_json.py生成完整特征
data = {
    "features": {
        "Time": 0.0,
        "V1": -1.3598,
        "V2": -0.0727,
        # ... 其他27个特征
        "Amount": 149.62
    },
    "explain": True,
    "use_llm": True,
    "model_name": "qwen3:4b"
}

response = requests.post(url, json=data)
result = response.json()

print(f"预测分数: {result['score']}")
print(f"预测标签: {result['label']}")
print(f"\nLLM解释:\n{result.get('llm_explanation', 'N/A')}")
if result.get('strategy_suggestion'):
    print(f"\n策略建议:\n{result['strategy_suggestion']}")
```

## 6. 常见问题

### 6.1 Ollama服务连接失败

**问题1**：运行 `ollama_chat.py` 时出现连接错误
```
ConnectionError: 无法连接到 Ollama 服务
```

**问题2**：API返回 `"ollama_available": false`

**诊断步骤**：

1. **检查 Ollama 是否安装**：
   ```bash
   ollama --version
   ```
   如果未安装，请访问 [Ollama官网](https://ollama.ai) 下载安装

2. **检查 Ollama 服务是否运行**：
   ```bash
   # 方法1：检查进程（Windows）
   tasklist | findstr ollama
   
   # 方法2：测试API连接
   curl http://localhost:11434/api/tags
   # 或使用 PowerShell
   Invoke-WebRequest -Uri http://localhost:11434/api/tags
   ```

3. **检查模型是否存在**：
   ```bash
   ollama list
   # 应看到 qwen3:4b
   ```

4. **检查端口是否被占用**：
   ```powershell
   # Windows PowerShell
   netstat -ano | findstr :11434
   ```

**解决方法**：

**方法1：启动 Ollama 服务**
```bash
# 如果服务未运行，手动启动
ollama serve
```
注意：Ollama 通常会在安装后自动启动，如果未启动，可能需要：
- Windows：检查 Ollama 服务是否在后台运行，或重新启动 Ollama 应用
- 确保 Ollama 应用已启动（检查系统托盘或任务管理器）

**方法2：拉取缺失的模型**
```bash
# 如果模型不存在
ollama pull qwen3:4b
```

**方法3：检查防火墙设置**
- 确保防火墙允许 Ollama 访问网络
- 确保本地回环地址（localhost）未被阻止

**方法4：使用自定义端口（如果默认端口被占用）**
如果 11434 端口被占用，可以：
1. 修改 Ollama 配置（`ollama.yaml`）使用其他端口
2. 或修改代码中的 URL（不推荐，需要修改多处）

**验证连接**：
```bash
# 测试基本连接
curl http://localhost:11434/api/tags

# 测试模型是否可用
ollama run qwen3:4b "你好"
```

### 6.2 模型文件未找到

**问题**：启动API时提示模型文件不存在

**解决方法**：
1. 确保已运行Project_A的训练脚本
2. 检查 `EDU/Project_A/models/lgbm_model.pkl` 是否存在
3. 检查 `EDU/Project_A/data/processed/` 下的文件是否存在

### 6.3 SHAP安装问题

**问题**：安装shap时出错

**解决方法**：
```bash
# 方法1：使用conda安装
conda install -c conda-forge shap

# 方法2：分步安装
pip install shap --no-deps
pip install numba scipy

# 方法3：使用预编译版本
pip install shap --upgrade
```

### 6.4 LLM解释生成慢

**问题**：LLM解释需要较长时间

**说明**：这是正常的，qwen3:4b在CPU上推理需要几秒到几十秒

**优化建议**：
1. 使用GPU加速（如果可用）
2. 减少解释的详细程度
3. 使用更小的模型（如果可用）

### 6.5 端口冲突

**问题**：端口8001已被占用

**解决方法**：
```bash
# 方法1：使用其他端口
# 设置环境变量
$env:PORT=8002
python src/api/app.py

# 方法2：修改app.py中的默认端口
```

## 8. 性能说明

- **预测速度**：LightGBM预测 < 1ms
- **SHAP解释**：单条样本约 100-500ms
