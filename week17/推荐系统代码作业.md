# 推荐系统代码作业

## 作业说明

本次作业要求实现一个电影推荐系统，包含两种推荐算法：
1. **物品协同过滤（Item-based Collaborative Filtering）**
2. **基于内容的推荐（Content-based Recommendation）**

## 作业要求

### 任务1：物品协同过滤推荐

实现基于物品的协同过滤推荐算法，要求：

1. **计算物品相似度**
   - 使用余弦相似度计算物品之间的相似度
   - 公式：`sim(A, B) = (用户同时喜欢A和B的数量) / sqrt(喜欢A的用户数 × 喜欢B的用户数)`
   - 返回物品相似度矩阵

2. **生成推荐列表**
   - 对于给定用户，找到其已评分的物品
   - 基于这些物品的相似物品生成推荐
   - 按相似度加权评分进行排序
   - 返回Top-N推荐列表

3. **推荐理由生成**
   - 为每个推荐物品生成推荐理由
   - 格式："因为您喜欢《电影A》，所以推荐《电影B》"

4. **代码质量**
   - 代码结构清晰
   - 有适当的注释
   - 函数命名规范

### 任务2：基于内容的推荐

实现基于电影内容的推荐算法，要求：

1. **特征提取**
   - 从电影数据中提取特征（类型、导演、演员等）
   - 将特征转换为向量表示（使用TF-IDF或简单编码）

2. **用户画像构建**
   - 根据用户历史评分记录构建用户偏好画像
   - 计算用户对不同特征的偏好权重

3. **相似度计算与推荐**
   - 计算候选电影与用户画像的相似度
   - 使用余弦相似度
   - 返回Top-N推荐列表（N不可以等于1）

4. **代码质量**
   - 代码结构清晰
   - 有适当的注释
   - 函数命名规范

### 任务3：综合推荐系统（可选）

实现一个综合推荐系统，要求：

1. **混合推荐**
   - 结合协同过滤和基于内容的推荐
   - 使用加权平均或其他融合策略

2. **推荐结果展示**
   - 格式化输出推荐结果
   - 包含电影名称、推荐分数、推荐理由
