## 作业要求

### 任务1：定义模型类
- 创建一个CNN模型类 `InferenceCNN`
- 要求：
  - 输入：3通道图像，尺寸为32x32
  - 包含2个卷积层和1个全连接层
  - 输出：10个类别的分类结果
- 可以参考 `代码脚本.py` 中的 `SimpleCNN` 类

### 任务2：模型导出为ONNX
- 实现 `export_model_to_onnx()` 函数
- 要求：
  - 使用 `torch.onnx.export` 导出模型
  - 设置合适的 `opset_version`（建议11或更高）
  - 支持动态 `batch_size`
  - 设置清晰的输入输出名称
  - 进行模型验证（可选，但建议）

### 任务3：PyTorch原生推理
- 实现 `pytorch_inference()` 函数
- 要求：
  - 正确设置模型为评估模式
  - 使用 `torch.no_grad()` 禁用梯度计算
  - 测量多次推理的平均时间（毫秒）
  - 返回模型输出和平均推理时间

### 任务4：ONNX Runtime推理
- 实现 `onnx_inference()` 函数
- 要求：
  - 检查 `onnxruntime` 是否可用
  - 创建 `InferenceSession`
  - 正确获取输入输出名称
  - 进行推理并测量时间
  - 处理数据类型转换（torch tensor -> numpy array）

### 任务5：性能对比
- 实现 `compare_inference_performance()` 函数
- 要求：
  - 对比推理速度（平均时间）
  - 对比模型文件大小
  - 对比输出结果的一致性（使用MSE）
  - 打印详细的对比报告，包括：
    - 推理时间对比
    - 模型大小对比
    - 输出一致性验证（MSE和最大绝对误差）

### 任务6：批量推理对比
- 实现 `compare_batch_inference()` 函数
- 要求：
  - 测试不同 batch size（1, 4, 8, 16）下的推理性能
  - 记录PyTorch和ONNX Runtime的推理时间
  - 打印性能对比表格
  - 分析不同batch size下的性能差异

## 常见问题

### Q1: ONNX导出失败怎么办？
- 检查模型是否包含不支持的操作
- 尝试降低 `opset_version`
- 检查输入数据的形状是否正确

### Q2: ONNX Runtime推理结果与PyTorch不一致？
- 检查数据类型转换是否正确（float32）
- 检查输入数据的预处理是否一致
- 允许小的数值误差（MSE < 1e-5通常可接受）

### Q3: 如何测量GPU内存占用？
- 使用 `torch.cuda.memory_allocated()` 获取GPU内存
- 注意：需要确保模型和数据在GPU上

### Q4: 批量推理对比时应该注意什么？
- 确保不同batch size下的输入数据形状正确
- 多次运行取平均值以获得更准确的结果
- 注意内存限制，避免batch size过大导致OOM
